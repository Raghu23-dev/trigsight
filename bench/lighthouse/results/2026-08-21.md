## Two failures Lighthouse caught that review had not

**Colour contrast, 3.78:1 against a required 4.5:1.** The `--color-fg-subtle` token
(`#646c7e`) failed WCAG AA on every surface. I had judged it by eye and it looked
fine. Replaced with `#788092`, *computed* rather than adjusted until the warning
disappeared — verified at 5.03 against `bg`, 4.81 against `surface`, 4.53 against
`surface-raised`, so it passes on the worst case not just the average.

A `text-fg-subtle/70` opacity variant measured 2.35:1 and was removed outright. An
inaccessible tier is not worth keeping for a shade of hierarchy.

**A missing favicon** produced a 404 console error, which cost Best Practices. Added
`src/app/icon.svg`.

Both were invisible without measurement. This is the argument for enforcing the
budget in CI rather than checking it manually before a launch.

## Why TBT fell from 460 ms to ~20 ms

The contrast fix was not the cause. Reducing the number of distinct colour values
let Tailwind emit less CSS, and removing the 404 removed a blocking request from the
critical path — but the dominant factor is that the WebGL scene never enters the
initial payload. It is behind five guards (reduced-motion, save-data, a WebGL2
capability probe, a device-memory/core heuristic, and `requestIdleCallback`), so on
the Lighthouse profile it is deferred past the measurement window entirely.


### One production-only failure, caught by deploying

The first deploy returned **HTTP 500 on both dynamic routes** while every static page
was fine. Cause: `readFileSync("content/…")` — a serverless function bundle does not
include the `content/` directory, so the call works locally and throws `ENOENT` once
deployed.

This is the worst shape of bug. Local testing cannot see it, the build succeeds, and
it disables exactly the two features that make the site more than static. Velite
already carries the raw MDX in its build output, so the filesystem read was never
necessary.

Fixed, plus 14 regression tests asserting no route or shared library imports
`node:fs` — comments are stripped before the check so the explanation of *why* fs is
avoided does not trip its own assertion.

**The lesson recorded for the remaining projects: "deployed" is a step in the
pipeline for a reason. A green build and a green test suite do not prove a system
runs.**
